# Universal Agents Desktop 0.6.3

This patch publishes the desktop documentation website and includes the approved
UA runtime versions released since Desktop 0.6.2.

- The README links to the published documentation and quickstart, introduces
  Universal Agents, and includes the short explainer video.
- Documentation builds check links and routes before publishing to GitHub Pages.
- Approved public repositories can use the local CI runners. Native builds still
  run only for trusted repository events; fork contributions use hosted
  documentation checks.
- New installations use UA 0.9.8, pinned to the immutable image
  `sha256:b0309c544db0f2891e12c7683e3dfcaa80d2ded92a4d5d1bf87b89fb14a2fa17`
  with host contract 3. Existing installations keep their selected runtime and
  data, and can choose an approved runtime update in the launcher.

## Install or upgrade

Install over Desktop 0.6.2 or another supported 0.6.x or 0.5.5 installation.
Your UA data and selected runtime remain in place. Data created by Desktop 0.4.x
with UA 0.5.0 or earlier is unsupported; the launcher explains this before startup.

- Windows x64: use the setup EXE or MSI. Both are unsigned; SmartScreen may ask
  you to confirm the first launch.
- macOS: use the universal DMG for Apple Silicon or Intel. The app is ad-hoc
  signed, without Developer ID signing or notarization. For a trusted download,
  use System Settings > Privacy & Security > Open Anyway if Gatekeeper blocks it.
  Native execution checks cover Apple Silicon; Intel is compiled only.
- Linux x64: use the DEB or AppImage. Packages are built on Ubuntu 24.04;
  compatibility with older userspace has not been established.

Each installer has a SHA-256 checksum. Follow the
[desktop quickstart](https://enzimo.github.io/universal-agents-desktop/quickstart/)
and [setup guide](https://enzimo.github.io/universal-agents/docker-compose-setup.html)
for Docker, Colima, WSL 2, provider accounts and server hosting. Keep operating
system security checks enabled.

## Validation

Publication requires successful tests and native builds for the exact release
commit on macOS, Windows and Linux. The release workflow promotes those five
installers and verifies their GitHub artifact digests before creating checksums.
The macOS build verifies the ad-hoc signature and both universal architectures.

UA 0.9.8 is checked against the current desktop host contract on native AMD64 and
ARM64 Docker engines. These checks cover onboarding, credential import with
synthetic data, chat and documentation routes, restart persistence, and rejection
of broken startup, import and workspace settings. They do not validate a real
provider account or replace interactive installation checks on a clean computer.
