# Universal Agents Desktop 0.6.1

This release installs Universal Agents 0.9.4 on new computers, adds an
**Updates** drawer for UA and launcher versions, and opens UA's credential
forms inside the app.

0.6.1 has the same features as 0.6.0. It is the first release from this
repository after it was recreated without its old history; 0.6.0 and earlier
release pages no longer exist.

- **UA 0.9.4 built in.** A first install gets UA 0.9.4 when GitHub cannot be
  reached, and otherwise the newest version on the compatibility list.
  Existing installs keep the UA version they run until you switch.
- **Updates drawer.** One place for everything about versions, opened from
  **Updates** in the header or from a small badge that appears when something
  changes:
  - **UA:** see a new version, **Download** it in the background, review its
    release notes, then **Switch and restart**. Nothing restarts until you
    choose to.
  - **Other versions:** the last five UA versions this launcher can run, with
    their dates, whether each one was checked against this launcher, and
    whether it is downloaded. You can pick a newer one instead of the newest.
    Older versions link only to their notes, because UA cannot safely open
    data a newer version has changed.
  - **Launcher:** when a newer desktop version is published, the drawer says
    so and opens its download page.
  - **Offer pre-release and unchecked versions** moved here.
- **Credential forms open in the app.** When an agent asks for a credential,
  **Open secure credential form** now opens the form in an app window. Before,
  the UA window turned white and the form opened in the browser. External
  links still open in your browser and no longer leave an empty window behind.
- **Cleaner layout.** Start, Restart and Stop are one group in an aligned
  header, with Close and Quit beside them; **Quit** shows "Stopping…" while UA
  stops. Agent Workspace sits beside the launch area. Private image access,
  the OpenAI subscription and recent logs are collapsible sections under
  **Advanced Settings**. Every button has a tooltip. Both windows open larger
  and fit the screen.

## Install or upgrade

Install over Desktop 0.6.0 or 0.5.5; your UA data and selected UA version stay as they
are. To move an existing install to UA 0.9.4, open **Updates**, choose
**Download**, review the notes, then **Switch and restart**. This version
cannot use data created by Desktop 0.4.x (UA 0.5.0 or earlier); the app
explains this when it opens and changes nothing. To start fresh, remove the
old `universal-agents-desktop` Docker container, move the desktop app-data
folder aside, and open the app again.

Download the installer for your platform below.

- Windows x64: use the setup EXE or MSI. Both are unsigned, so SmartScreen may ask you to confirm the first launch.
- macOS: use the universal DMG for Apple Silicon or Intel. The app is ad-hoc signed, without Developer ID signing or notarization, so Gatekeeper may ask you to confirm the first launch. Native execution tests cover Apple Silicon; Intel is compiled only.
- Linux x64: use the DEB or AppImage. Builds use Ubuntu 24.04; older userspace compatibility has not been established.

On macOS with Colima, a private image needs a Docker credential helper: run `brew install docker-credential-helper` and set `"credsStore": "osxkeychain"` in `~/.docker/config.json`. The app checks this before downloading and explains it if needed.

Each installer has a SHA-256 checksum. Follow the [Quickstart](https://github.com/enzimo/universal-agents-desktop/blob/v0.6.1/QUICKSTART.md) or download the [comprehensive setup guide](https://github.com/enzimo/universal-agents/releases/latest/download/setup-guide.html) for Docker, Colima, WSL 2, provider accounts, and hosted-server setup.

## Runtime and validation

The built-in UA version is 0.9.4, pinned by digest (`sha256:e1389327…`) for Linux x64 and arm64. The compatibility list also contains UA 0.8.5 and 0.9.0 to 0.9.3, but their images were removed from the registry and can no longer be downloaded; choose UA 0.9.4 in **Updates**. An install still running one of them keeps working with the image it already has, but any step that downloads the image again, such as changing the Agent Workspace folder, can fail until it switches to UA 0.9.4. UA's GitHub releases before 0.9.4 no longer exist, so the Updates drawer shows those versions without a date or notes link.

UA 0.9.4 was added to the list after a review: its image matches the UA release, the UA files this launcher depends on are identical to UA 0.9.3, and the credential import smoke test passed with the published arm64 image.

Publication requires successful builds and tests for this exact source commit on the local macOS, Windows, and Linux runners. Installer archives are verified against GitHub artifact digests before publication. On macOS and Windows the native UI suite exercises the real Status window; on Windows and Linux a native probe checks that credential forms open in an app window. A fresh install of UA 0.9.4 from this build and the in-app switch from an earlier UA version remain manual acceptance checks.
