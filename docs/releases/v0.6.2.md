# Universal Agents Desktop 0.6.2

This release tells new users, the first time the launcher opens, that agents
need a computer that stays on.

- **Agents need a computer that stays on.** Universal Agents runs on your own
  computer, and agents stop working while it sleeps, so scheduled tasks can
  run late or be missed. The first time the launcher opens, right after
  **Click to Begin**, a short message says so and gives two choices:
  - keep this computer awake, with the exact sleep setting to change on
    macOS, Windows or Ubuntu;
  - or, if you are comfortable with Docker, run Universal Agents on a server
    instead. **Open setup guide** opens the setup guide that explains how.

  Choose **Got it** to close it. It shows once on each computer, including once
  after you upgrade.
- **Quickstart fixes.** **Use GitHub CLI** already downloads and starts UA, so
  the Quickstart no longer asks you to choose **Start** afterwards. On macOS
  the Keychain helper for Docker is now part of the normal setup steps,
  because a private image cannot be downloaded without it.

## Install or upgrade

Install over Desktop 0.6.1 or earlier 0.6.x and 0.5.5 releases; your UA data
and selected UA version stay as they are. This version cannot use data
created by Desktop 0.4.x (UA 0.5.0 or earlier); the app explains this when it
opens and changes nothing.

Download the installer for your platform below.

- Windows x64: use the setup EXE or MSI. Both are unsigned, so SmartScreen may ask you to confirm the first launch.
- macOS: use the universal DMG for Apple Silicon or Intel. The app is ad-hoc signed, without Developer ID signing or notarization, so Gatekeeper may ask you to confirm the first launch. Native execution tests cover Apple Silicon; Intel is compiled only.
- Linux x64: use the DEB or AppImage. Builds use Ubuntu 24.04; older userspace compatibility has not been established.

On macOS with Colima, a private image needs a Docker credential helper: run `brew install docker-credential-helper` and set `"credsStore": "osxkeychain"` in `~/.docker/config.json`. The app checks this before downloading and explains it if needed.

Each installer has a SHA-256 checksum. Follow the [Quickstart](https://github.com/enzimo/universal-agents-desktop/blob/v0.6.2/QUICKSTART.md) or download the [comprehensive setup guide](https://github.com/enzimo/universal-agents/releases/latest/download/setup-guide.html) for Docker, Colima, WSL 2, provider accounts, and hosted-server setup.

## Runtime and validation

The built-in UA version is still 0.9.4, pinned by digest (`sha256:e1389327…`) for Linux x64 and arm64, and the compatibility list is unchanged.

Publication requires successful builds and tests for this exact source commit on the local macOS, Windows, and Linux runners. Installer archives are verified against GitHub artifact digests before publication. On macOS and Windows the native UI suite exercises the real Status window, including the new first-run message.
