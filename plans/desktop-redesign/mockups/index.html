Universal Agents Desktop · redesign

Four layout concepts

Mockups only: buttons don't do anything except the mockup bar at the bottom of each page, the confirmation dialogs and the theme switch. They use the app's real colors, buttons and background.

What every concept fixes

  • UA version choice: the last five UA releases are always listed, each saying whether it works with this launcher and whether it's already downloaded, with Download and Switch. Pre-release and unchecked versions appear only when you ask for them.
  • No dead ends: an available update never lives only in a notification. The version list (or the Updates button) always shows the next step.
  • Launcher self-update: a floating badge, Available → Downloading → Restart launcher. UA keeps running while the launcher restarts.
  • Header alignment: one row, one Start / Restart / Stop group, status and theme at the same height. Progress is a thin bar under the header, so buttons don't jump.

Concept A

Home with a version list

  • Today's layout, reorganized. Status and Open on the left, Choose which UA runs on the right.
  • Access, logs and settings become summary cards.
  • Smallest change to build.

Concept B

Sidebar with a Versions page

  • Sections: Home, Versions, Access, Logs, Settings.
  • One page holds both the launcher update and a UA version table.
  • Scales best as the launcher grows. One extra click to reach anything.

Concept C

Compact window with a version picker

  • A small window: status, Open, version, Start / Restart / Stop.
  • The version opens a picker sheet with the last five releases.
  • Least intimidating. Logs and access move behind links.

Concept D

Update center drawer

  • Home stays about your team. An Updates drawer shows each update as a checklist with the next step.
  • Other versions are listed at the bottom of the drawer.
  • Very clear steps, but versions are hidden until you open it.
