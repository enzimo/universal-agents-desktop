Advanced Settings

Private Image Access

Private GHCR images need a GitHub account with package access. Sign-in replaces Docker's saved GHCR account for other Docker clients too. Credentials stay in Docker's configured credential helper, outside UA.

Already signed into Docker? Verify access and retry.

Sign in with gh opens a terminal for GitHub's browser login. Complete it and installation continues automatically. For multiple accounts, select the account in gh first.

Use a personal access token instead

Use a classic PAT with read:packages and access to the private package. Your organization may also require SSO authorization.

        Agents need a computer that stays on

          properly, Universal Agents needs to run 24/7. While this computer sleeps, agents stop
          working, and scheduled tasks can run late or be missed.
