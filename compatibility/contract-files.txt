# UA source files that define the desktop host contract.
#
# The desktop launcher depends on how these Universal Agents (UA) files lay out
# /data, start the container, and import or test OpenAI subscription logins.
# UA has no test of its own that tells it when a change breaks the launcher.
#
# scripts/check_compatibility_list.py uses this list when a pull request adds
# a UA version to compatible-runtimes.json. For each new version it compares
# every file below, by git blob SHA, between UA tag v{previous} (the newest
# listed version with the same host_contract_version) and tag v{new}. If any
# file differs or is missing on either side, the pull request is not merged
# automatically and a person must review it. See docs/COMPATIBILITY_LIST.md.
#
# How to change this list:
# - Add a path when the launcher starts depending on another UA file. Remove a
#   path only when the launcher no longer depends on it.
# - Paths are relative to the root of the enzimo/universal-agents repository,
#   one per line. Lines starting with # and blank lines are ignored.
# - Changing this file changes more than compatible-runtimes.json, so that pull
#   request is never merged automatically; it needs normal review.
